MethodDka

最大200次対応 ＆ 50桁高精度 多項式解法・因数分解 Web アプリ

🚀 Web アプリを起動する

✨ 主な機能と特徴

  • 📋
    係数データの一括ペースト機能
    スペース・改行・カンマ区切りのテキストデータを一括で貼り付けるだけで、すべての入力欄へ一発セットできます。
  • ⚡
    最大 200 次対応 ＆ オートスケーリング（規格化）処理
    高次計算時や巨大・極小係数の混在時にも、自動スケーリング処理によりオーバーフローやアンダーフローを防止します。
  • 🎯
    50 桁高精度解 ＆ 因数分解表示の即時切替
    トグルスイッチ一つで「50桁高精度解表示」と「因数分解表示（四捨五入）」を再計算なしで即座に切替可能です。
  • 🌐
    完全マルチプラットフォーム ＆ オフライン対応
    ブラウザ（Chrome, Edge, Safari等）上で単一ファイルとして完全にローカル動作するため、オフライン環境でも安全にご利用いただけます。

🛠️ 使い方

  1. 上のボタンから `MethodDka.html` を開きます。
  2. 最高次数（例: 10）を入力し、「生成」 を押します。
  3. 係数を手入力するか、「📋 係数データの一括ペースト」 エリアに貼り付けて 「一括反映」 を押します。
  4. 「計算開始」 を押すと、瞬時に全複素数解および誤差半径・反復回数が出力されます。
  5. モード切替トグルで、必要に応じていつでも因数分解表示に切り替えられます。

💡 技術仕様 ＆ 学術注記

  • アルゴリズム: DKA法（Durand-Kerner 法）による並列収束探索
  • 高精度演算エンジン: Decimal.js (precision: 50)
  • スケーリング手法: 係数の幾何平均スケール因子 $S = |a_n / a_0|^{1/n}$ による規格化処理
💡 補足（悪条件多項式について）:
本アプリはオートスケーリング処理により最大200次までの計算に対応していますが、ウィルキンソン多項式のように「根が実軸上に極めて密集して並ぶ悪条件多項式（Ill-conditioned polynomials）」では、並列円周初期値を用いる DKA 法の性質上、高次（15次以上）で複素数領域の鞍点へ引き込まれる（偽収束する）場合があります。通常分散された多項式では高次まで正常に動作します。
